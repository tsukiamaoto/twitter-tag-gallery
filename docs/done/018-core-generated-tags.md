# 模型與自動標籤限制為核心分類

日期：2026-10-21

## 範圍與行為

使用者選擇保留畫師、角色、作品、來源及人工標籤，並要求限制模型重新產生標籤的流程。

- 自動寫入只接受 `artist`、`character`、`copyright`、`source`。
- `tag_policy.py` 定義共用規則；`database.ensure_tag(..., source=...)` 在查快取前篩除不允許的自動分類。
- 本機 AI 只輸出畫師、角色與作品；單張分析、批次、排程、反向搜圖及 Pixiv 救援的動態分類寫入均套用規則。
- 掃描不再從日期、特殊資料夾或檔名產生年份、一般描述；去馬賽克處理只留下來源標記，不新增一般描述，也不移除人工標籤。
- MCP 編輯工具要求明確指定核心分類，來源記為 `gemini_mcp`，不能以人工來源繞過，也不能覆蓋或移除人工標籤。網頁人工新增標籤仍可使用其他分類。
- 舊 `add_general_tags`、主題群組參數僅接受空值；`auto_cluster_builtin_themes` 固定為 false。直接呼叫舊工具服務也會在任何寫入前拒絕非空參數，避免混合批次部分成功。
- 模型翻譯工具仍可更新既有翻譯，不再建立主題關聯；舊主題產生 API 回傳 410。
- 智慧標籤介面移除主題分類步驟與一般描述門檻，說明只保留核心分類。技能 `.agents/skills/twitter-tag-correlation/SKILL.md` 同步更新模型流程、分類與來源規則。

既有標籤已於使用者明確同意後完成清理：1,189,635 筆圖片標籤關聯精簡為 130,293 筆，移除 1,059,342 筆非核心自動關聯。圖片原檔不在本次標籤限制或清理的修改範圍；完整執行與驗證見下方「既有標籤正式清理」。
