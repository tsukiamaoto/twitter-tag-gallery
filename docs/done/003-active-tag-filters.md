# 003 — 標籤篩選的取消操作

狀態：done  
開始日期：2026-10-20  
完成日期：2026-10-20

## 目標

讓使用者隨時知道目前套用了哪些標籤，能直接取消單一條件。標籤只提供加入／取消，保留多標籤疊加。

## 驗收

- [x] 工具列有清楚的已選條件區及數量。
- [x] 每個標籤條件有可辨識、鍵盤可操作的移除按鈕。
- [x] 左欄標籤顯示已選狀態，取消時同步。
- [x] 清除標籤只清除標籤；重設全部篩選仍可使用。
- [x] 多標籤、單一取消與清除後，結果及狀態一致。
- [x] 點標籤只切換加入／取消，名稱與數量都在同一按鈕內。
- [x] 移除排除按鈕、右鍵排除、排除狀態與相關提示；前端查詢不再傳送排除條件。

## 驗證結果

- 隔離測試確認多標籤可疊加、再點會移除，清除標籤不更動既有資料夾與搜尋文字。
- `node --test tests/webui.test.cjs`：13 項通過（含後續新增的資料夾選取器檢查）。
- 標籤與資料夾條件只影響瀏覽查詢，未修改圖片上的實際標籤。

- 使用既有 Playwright 模擬圖庫，在桌面 1440px 與手機 390px 連續點擊同一座標四次，確認加入／取消交替，查詢不帶 `exclude_tags` 參數；另外驗證點數量也可加入、條件列移除與 Enter／Space 操作。
- 確認介面沒有排除控制項或右鍵處理器；右鍵事件不改動標籤選取或發出篩選查詢。
- 既有瀏覽器驗證的 15 種寬度（320–2507px）通過，沒有 JavaScript 錯誤或圖庫寫入請求。已檢視 `.tag_gallery/ui-review/tags-simple-desktop.png` 與 `tags-simple-mobile.png`。
