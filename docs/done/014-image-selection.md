# Shift 範圍多選與左鍵拖曳勾選

日期：2026-10-21

## 操作

- 先勾一張，再按住 Shift 點另一張的勾選框或圖片，選取本頁顯示順序中兩者之間的全部圖片，支援正向／反向及跨列。
- 勾選框支援 Space／Enter 切換，Shift＋Space／Enter 連選；縮圖也支援 Shift＋Enter／Space 連選。
- 按住滑鼠左鍵，從圖片或勾選框拖過其他卡片即可連續勾選；起點已勾選時改為連續取消。左鍵不放開往回掃，離開後再次進入的圖片會切換勾選狀態，支援持續來回調整；在同一張內移動不會反覆切換。
- 快速掃過一整排也會處理中間圖片。放開左鍵、指標取消、失焦、視窗尺寸改變或清單重繪後結束拖曳。
- 一般點縮圖仍開啟詳情；Shift 連選或拖曳不開圖、不點標籤、不觸發刪除。右鍵與觸控拖曳不啟動塗選。
- 多頁已選項目仍保留；Shift 的錨點不在目前頁面時只選取點擊的圖片，避免意外勾選其他範圍。

## 實作

共用既有 `selectedIds`、選取數量及批次操作。選取時只更新卡片 class、勾選符號與 `aria-checked`，不重建整個圖片網格。拖曳期間固定批次工具列的顯示狀態，到放開滑鼠才顯示／隱藏，避免圖片在滑鼠下突然位移。

指標路徑和卡片可見矩形做線段相交判定，補上快速移動時跨過的圖片；pointer capture 確保移出網格後放開也能結束。拖曳完成後攔截同一手勢的 click，下一次正常點擊不受影響。新增提示於勾選框、全選按鈕與批次工具列。

## 驗證

- JavaScript 27 項通過，新增顯示順序範圍、反向範圍、跨頁錨點、線段相交及來回拖選測試。
- 模擬瀏覽器測試通過：Shift 點圖／勾選框、Shift＋Space、Space 單次切換、快速及反向拖曳、連續取消、同次手勢來回切換、卡片內移動不重複切換、原地更新 DOM、網格不跳動、放開後正常點擊、網格外釋放、右鍵不勾選、跨頁保留、響應式排列及批次刪除串接。
- 正式 HTTP 已提供新版 JavaScript、CSS 與提示，只需重新載入前端，不需要重啟服務。

所有驗證使用模擬 API，未操作正式圖片或資料庫。選取本身不送出任何寫入請求。
