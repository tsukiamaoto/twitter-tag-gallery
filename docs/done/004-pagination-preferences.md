# 004 — 每頁數量與方向鍵分頁

狀態：done  
開始日期：2026-10-20  
完成日期：2026-10-20

## 目標

可自行輸入每頁數量（10–200）並保存瀏覽偏好；使用左右方向鍵在圖庫翻頁。

## 驗收

- [x] 分頁區與設定中心可調整每頁數量，有範圍驗證。
- [x] 改變數量回第一頁，頁碼及顯示數量一致。
- [x] 重新整理仍保留數量設定，儲存不可用時仍能瀏覽。
- [x] 左右鍵支援上一頁／下一頁，首頁及末頁不越界。
- [x] 輸入欄位、下拉選單、其他彈窗及組字時不觸發分頁。
- [x] 詳情開啟時仍用左右鍵切換圖片。
- [x] 窄畫面搜尋與分頁控制不溢出。

## 驗證結果

- 實際輸入 37，顯示每頁 37 張及 839 頁（當時圖庫 31,042 張）；重新整理後仍為 37。
- 輸入 9 時顯示原生範圍錯誤，實際每頁數量保持 37；驗收結束已恢復原先的 60。
- 實際按右方向鍵由第 1 頁到第 2 頁；搜尋欄內按右鍵不翻頁，設定開啟時也不翻頁。
- 詳情中按右鍵由第一張切到第二張，圖庫頁碼保持不變。
- 偏好中的快捷鍵開關及預覽開關關閉後，重新整理仍保留，再恢復啟用。
- 隔離測試覆蓋首頁／末頁邊界、輸入控制、彈窗、組字、修飾鍵、連按與儲存不可用；也驗證較慢的舊查詢不會覆蓋新結果。
- 窄視窗實際確認搜尋列及分頁控制換行，頁面沒有水平溢出。
