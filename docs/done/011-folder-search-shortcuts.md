# 011 — 資料夾搜尋與常用捷徑

狀態：done  
完成日期：2026-10-20

## 需求與結果

圖庫已有 1,847 個資料夾，使用者同意將資料夾頁面改為搜尋優先，預設顯示釘選與最近使用，完整清單按需展開，並提供名稱、圖片數、最近更新排序。

- 預設只顯示釘選與最近使用捷徑；沒有紀錄時提供簡短使用提示。
- 搜尋支援部分名稱、大小寫及全形英數正規化；有搜尋文字時只顯示符合結果。
- 以星號釘選／取消釘選；最近使用記錄最近 12 個實際開啟的資料夾，釘選項目不重複出現在近期捷徑。
- 釘選、最近使用與排序儲存在此瀏覽器的 `gallery.folders.preferences`。儲存不可用時，本次操作仍可使用並顯示回饋；損壞偏好使用預設值，重新取得資料時移除已不存在的捷徑。
- 搜尋結果及完整清單每次顯示 100 筆，可繼續載入。完整清單重新開頁時預設收合。
- 釘選、搜尋、排序與展開清單不重新查詢圖片；開啟資料夾沿用原有篩選，保留標籤條件並回到第一頁。
- 資料夾讀取失敗可重試，不讓錯誤回應蓋掉已取得的有效資料；重建清單後保留鍵盤焦點。

## 更新時間與相容性

`/api/folders` 保留 `name`、`count`，新增 `last_updated`，取資料夾內圖片的最大 `mtime`。最近更新指圖片檔案的最新修改時間，並非最近歸檔或瀏覽時間；日期以 Asia/Taipei 顯示。較舊 API 沒有此欄位時，介面不虛構日期，暫停用該排序。

沒有修改 `static/index.html`。前端位於獨立 shell 檔案，後端只增加資料夾時間欄位；未移動圖片或更改標籤。整合時服務暫時未監聽，使用既有背景啟動器確保服務可用，沒有停止其他背景處理。
