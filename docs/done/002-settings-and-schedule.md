## 目標

主畫面加入「設定」入口，將排程歸入設定中心。提供瀏覽偏好、匯入排程、執行紀錄；常用設定優先，長說明及進階處理細節收合。保留原有排程 API 與儲存方式。

## 驗收

- [x] 主畫面以設定入口取代獨立彩色排程按鈕。
- [x] 排程基本畫面保留啟用、時間與來源資料夾。
- [x] 進階處理選項與說明可展開，紀錄有獨立區域。
- [x] 儲存與立即執行清楚分開，錯誤有回饋。
- [x] 窄畫面可捲動、關閉；鍵盤焦點及 Escape 可操作。
- [x] 不為驗收而啟動真實搬移或修改 Windows 排程。
