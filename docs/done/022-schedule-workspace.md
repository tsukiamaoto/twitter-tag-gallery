# 022 — 左側排程入口與匯入排程頁面

狀態：done  
完成日期：2026-10-24

## 功能與操作

- 左側工具列依序為首頁、排程、AI。排程改為獨立工作區，一般設定保留瀏覽偏好、操作日誌與背景任務。
- 桌面使用設定與總覽雙欄；手機改為單欄，時間欄位直向排列，儲存操作固定於底部。
- 依執行時間、來源資料夾、匯入後處理排列設定。支援鍵盤操作的原生時間輸入、可選第二時段、原生資料夾選擇與手動路徑。
- 總覽顯示依本機時間計算的下次執行預覽、來源數量、執行方式與已啟用的處理流程。明確標示草稿預覽及未儲存變更。
- 執行紀錄與待機／執行中狀態在排程頁顯示；重新整理狀態與背景輪詢不覆寫表單。
- 執行紀錄移至設定下方的整欄區塊，預設顯示最近三次，可展開全部紀錄。每次先顯示時間、觸發原因、搬入／打標／歸檔數量與耗時；空資料夾、新建畫師資料夾等細節按需展開，取消紀錄區內的獨立捲軸。
- 匯入後處理收合時只顯示啟用項數，整列可點擊，附文字與箭頭的展開／收合入口。展開後依辨識標籤與歸檔整理分組，窄螢幕自動直排。
- 背景輪詢在紀錄未變更時保留原 DOM、鍵盤焦點與展開狀態；新增紀錄後仍保留既有詳情及查看全部的選擇。
- 切換首頁、AI 或開啟一般設定會保留排程草稿。圖庫原有篩選、選取、頁碼及捲動位置保持於已掛載的首頁。
- 載入失敗可直接重試，載入前不能提交。來源未設定、不完整時間及重複時段會阻止提交；儲存失敗不執行任務，背景任務忙碌會顯示啟動失敗原因。

## 整合

`workspace-navigation.js` 移動既有表單及操作按鈕至排程工作區，不複製 DOM。`schedule-workspace.js` 管理草稿比較、總覽、來源計數及狀態更新，`schedule-workspace.css` 提供獨立的響應式版面。原本的 `openSettings('schedule')`、`switchSettingsTab('schedule')` 與 `openScheduleModal()` 皆轉入新工作區。

沿用 `/api/schedule/*`、既有資料格式與設定檔。儲存保留未顯示的 AI 門檻及反查數量限制。離開排程頁不停止正在執行的工作。
