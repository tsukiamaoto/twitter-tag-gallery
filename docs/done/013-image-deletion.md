# 圖片單檔、多選刪除與 Del 快捷鍵

日期：2026-10-21

## 行為

- 勾選圖片後，批次工具列提供「刪除選取檔案 (Del)」，包含跨頁選取。
- 單張詳情提供「刪除檔案 (Del)」。在詳情按 Del 只刪除目前這張。
- 圖庫按 Del 刪除已選取項目；沒有選取時，可刪除目前鍵盤焦點所在的圖片卡片。
- 刪除前確認數量、最多五個檔名與跨頁選取數量。取消不送出請求。
- 輸入欄位、影片控制、輸入法組字、其他對話框、組合鍵與長按重複事件不觸發刪除。
- 成功後同步選取、圖片、統計、標籤與資料夾；刪完末頁會調回有效頁碼。
- 「復原剛才刪除」保留最後一次成功刪除的批次，重新整理後仍可復原。

## 檔案與資料

`POST /api/images/delete` 接受明確的正整數 `image_ids`（最多 10,000 個），全批檢查 ID 與檔案後執行。檔案實際移到原圖庫的 `.tag_gallery/trash/<operation_id>/`，同步移除 SQLite 圖片與關聯索引；掃描會略過回收區。這是圖庫自己的回收區，並不釋放磁碟空間。

`POST /api/images/deletions/<operation_id>/restore` 復原原位置、圖片 ID、人工與自動標籤、翻譯及處理階段。原位置有同名檔、索引衝突或回收區內容已修改時，停止全批復原，不覆蓋檔案。失敗後可重試，已復原的批次不可重複執行。

使用既有 `exclusive_job` 與 `file_operations.execute`：完整計畫持久化後才搬檔，資料庫一次提交；搬移或寫入失敗會回滾，程序中斷可由既有復原工具處理。刪除日誌保存必要的圖片、標籤及處理資料，復原交易失敗時也會退回回收區。

介面提供最後一批的復原按鈕；更早批次的 ID 留在操作日誌，可透過復原 API 處理。本次未增加回收區清空或永久刪除功能。
