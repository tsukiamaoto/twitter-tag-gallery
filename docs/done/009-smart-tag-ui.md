# 009 — 智慧標籤與 AI 模型設定

狀態：done  
完成日期：2026-10-20

## 需求與結果

使用者要求簡化智慧標籤視窗，並將模型載入／卸載移到設定。

- 智慧標籤保留處理範圍、本機分析上限、三個主要步驟、歸檔選項及執行進度。
- 縮短名稱與說明，移除同時展開的多色參數區，統一視覺層級。
- 辨識門檻、搜圖參數、既有其他處理選項與維護工具收進「進階參數與工具」。
- 底部保留單一主要動作與處理摘要，進階內容可捲動，關閉與啟動按鈕保持可見。
- 設定新增「AI 模型」頁簽，集中載入、卸載、自動卸載偏好與硬碟快取管理；移除主畫面管理選單的重複模型入口。
- 智慧標籤提供模型設定捷徑，設定關閉後可返回智慧標籤，並恢復焦點。
- 執行中停用新的處理與模型操作，顯示即時進度；排程不顯示無法停止該排程的停止按鈕。
- 啟動／模型操作失敗使用區域內回饋，刪除快取保留原有確認步驟。

## 相容性

保留原有控制項 ID、值與預設勾選狀態，沿用既有 API；重新整理前端即可載入，沒有修改 `static/index.html` 或後端。啟動表單參數和原有 API 對應不變，新增數字驗證及重複送出防護。

自動卸載偏好以 `gallery.model.autoUnload` 儲存在此瀏覽器；每次新任務由 `auto_unload` 參數送出。更改此偏好不改變已執行中的任務。

## 驗證

- `node tests/smart-tag-ui.spec.cjs`：1440、1024、768、600、390、320px 通過；沒有未捕捉 JavaScript 錯誤。
- 模擬驗證：保留預設範圍與步驟、參數映射、自訂張數、數值驗證、進度、停止、忙碌狀態、載入／卸載、取消及確認刪除快取、錯誤回饋、偏好保存。
- 設定四頁簽方向鍵／Home／End、智慧標籤焦點限制、Escape 與設定返回焦點通過。
- `node tests/gallery-shell.spec.cjs`：原有 15 種寬度與側欄／工具列回歸通過。
- `node --test tests/webui.test.cjs`：原頁面 13 項隔離驗證通過。
- 實際服務唯讀檢查：新版智慧標籤與設定入口可開啟與返回；沒有 POST 請求或 JavaScript 錯誤。

模型操作及任務啟動測試全部使用攔截的模擬 API，沒有操作真實模型、快取或圖片，也沒有停止服務與背景任務。
