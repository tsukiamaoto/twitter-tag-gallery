# 005 — 圖片停留預覽

狀態：done  
開始日期：2026-10-20  
完成日期：2026-10-20

## 目標

滑鼠停留於縮圖後顯示較大的完整比例圖片，移開即關閉；不改變網格版面，仍可點擊開啟詳情。

## 驗收

- [x] 停留短暫延遲後顯示，不因快速掃過而閃爍。
- [x] 預覽保留圖片比例，不超出視窗且不攔截滑鼠。
- [x] 移開、捲動、翻頁、開彈窗或 Escape 時關閉。
- [x] 快速換圖不顯示上一張的遲到內容；載入失敗可恢復。
- [x] 可在設定中心關閉並保存偏好。
- [x] 觸控維持點擊詳情；影片使用靜態縮圖預覽、不自動播放。

## 驗證結果

- 實際以滑鼠移入縮圖，確認停留後出現完整比例原圖預覽，原網格不位移。
- 實際量測預覽邊界位於視窗內；Escape 及開啟詳情時預覽關閉。
- 設定中的預覽開關重新整理後仍保持，驗收結束已恢復啟用。
- 隔離測試覆蓋停留計時取消、舊圖遲到回應、載入失敗關閉、停用時不請求圖片，以及影片僅使用縮圖端點。
- 捲動、視窗變更、失去焦點及翻頁都會清除待顯示預覽；觸控 pointer 不觸發滑鼠停留處理，仍能點擊詳情。
- `node --test tests/webui.test.cjs`：10 項通過。
- 限制：未使用實體觸控裝置驗證；觸控行為以事件處理邏輯與原有點擊流程確認。
