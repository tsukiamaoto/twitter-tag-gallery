## 需求與範圍

- 改名預覽一次查詢取得資料，歸還連線後在記憶體分組、排序。
- 預覽使用最多 4 條連線的專用唯讀池；保留其他背景工作既有的 `get_db()` 介面。
- 已歸還的連線閒置 60 秒後自動關閉，無使用時可縮到 0 條。
- 發生例外也必須歸還，回滾未提交交易；重設失敗的連線直接丟棄。
- 不依瀏覽器人數判斷使用狀態，不強制關閉借出中的連線。

## 驗收

- [x] 單一與全部資料夾預覽都只讀取一次，輸出及自然排序規則保持一致。
- [x] 預覽排序開始前已歸還連線。
- [x] 閒置 60 秒回收、例外歸還、借出互斥及使用中不關閉的測試通過。
- [x] 以真實圖庫的唯讀快照量測改名前後結果及時間，不執行檔案改名。

## 實作

- `sqlite_pool.py` 以條件鎖管理獨佔借出，按需建立最多 4 條連線；等待借用最多 5 秒，逾時不搶占現有使用者。
- 以 monotonic 時鐘記錄歸還時間；背景回收器到期即清理閒置連線，不依賴下一個請求。
- context manager 的 `finally` 會歸還並回滾未提交交易。重設失敗則丟棄，建立失敗也會釋回容量。
- 關閉池時只處理閒置連線，已借出者等歸還才關閉；不強制中斷 SQL。
- `database.get_preview_db()` 提供專用唯讀池；舊 `get_db()` 介面保留，並補上初始化失敗時關閉連線。
- `renamer.generate_rename_preview()` 一次查詢並釋回連線，交給共用的純計畫函式分組、排序。執行改名仍依原流程重新產生計畫。

- 60 秒邊界使用可控 monotonic 時鐘驗證；背景主動回收另外用短期限的真實執行緒驗證。
