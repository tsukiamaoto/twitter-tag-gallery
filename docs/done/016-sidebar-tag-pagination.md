# 016 左側標籤按捲動分批載入

狀態：done（已確認正式服務）  
完成日期：2026-10-21

## 需求與實作

- 左側標籤由一次載入 250 筆改為每批 40 筆，接近清單底部時追加下一批。
- 新增 `/api/tags?paged=true&offset=0&limit=40` 分頁回應；既有 API 預設仍回傳陣列。
- 分頁在畫師別名合併後切片；「最近」及時間區間項目也包含在同一分頁序列。
- 追加項目保留既有 DOM 與捲動位置；分類、搜尋或資料刷新時取消舊請求並重設分頁。
- 失敗保留既有項目並顯示重試；保留鍵盤操作的載入更多按鈕。

## 範圍與限制

分頁仍沿用畫師別名合併及「最近」排序快取，後端依所需排序前綴切片；不是游標分頁。本次降低首次下載與建立的標籤項目數，已捲過的項目保留在 DOM。資料內容持續變動時沿用一般 offset 分頁語意，前端會按標籤名稱去除重複，資料刷新則重新載入首批。
